# Shape brief: Partners Lab Stripe redesign

Register: product (demo tool, not a marketing landing).

Scene: a founder sits at a bright desk in the afternoon, checking Roberto's Stripe Connect demo on a laptop. They need to see one payment split, try Checkout, and leave with a clear picture of what is sandbox and what is still a proposal.

Color strategy: restrained. Cool pale blue canvas, near-white cards, navy type, indigo only on the primary action and the selected tab. No beige, no green slabs.

Layout: slim header with mark, Sandbox chip, tabs, code link. Compact heading. Form and breakdown side by side above a 1000px fold. Empty session activity. Local ledger inside a collapsed disclosure. Partners and Lanzamiento keep their full content.

Typography: system sans, fixed rem scale, tight product hierarchy. No serif, no fluid hero type.

Assets: native inline SVG only. The imagegen PNG is a mock, not a runtime image.

Motion: none beyond open/close of details. State is copy, disabled controls, and pending values.

Anti-references: giant marketing hero, green utility forms, fake transaction tables, fabricated Stripe fees, Express-as-if-shipped, production claims.
